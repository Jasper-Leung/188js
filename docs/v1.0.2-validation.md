# v1.0.2 验收记录

日期：2026-10-16。项目扫描与经营完整方案见 [v1.0.2-plan.md](v1.0.2-plan.md)。本文件区分代码验证、浏览器操作和未测设备；本地版本号不代表 GitHub 已发布。

## 审计与计划

起点为 main / 9808ebe，初始工作树干净。实际工程是 TypeScript strict、three.js 0.169、Vite 6 和 Tauri 2；场景、建筑、植被、骨骼均由 TS 与 GLB 构造，没有 Unity 场景或预制体。运行 `npm run dev`，生产构建 `npm run build`，产物预览 `npm run preview`，唯一回归入口 `npm run verify`。

主要风险：经营收入放宽原旅币预算；五分钟视觉昼夜不能推进原三十天期限；骨骼烘焙失败须保留机械车轮；横屏锁定与 XR 取决于设备能力；桌面三平台依赖 CI。本机现已装上 Rust 1.93（cargo/rustc），可以本地构建并试跑 Windows 安装包，但**三平台**仍只能靠 CI。

实施按文档、数值/存档核心、世界/骑行、UI/XR/集成与发布准备分批提交。不运行覆盖原资产的资源重生成管线；没有修改现有剧情站号、碎片轮换、主线结束条件或存档版本。

## 人工验收步骤（未完成项不能标通过）

1. 在 iPhone Safari 与 Android Chrome 真机分别打开 HTTPS 版本，覆盖 16:9、19.5:9、20:9 横屏；从竖屏进入，尝试横屏按钮、拒绝全屏/方向锁，再物理旋转。检查刘海、底部手势区、地址栏收缩和后台恢复。
2. 同时推动摇杆与点击换车/交互/打卡；左右手布局各一次。按住移动时旋转、切应用后回来，必须停止输入。确认小地图、任务、碎片、道具栏不被手指和菜单盖住；暂停、经营、商店、明信片都能退出。
3. 自行车 1、5、8、12、15m/s 各骑 20 秒，加减速、停走、换车后再骑；近距离侧面看双脚贴踏板、左右交替、膝盖方向、鞍面和手臂。
4. 沿完整主路访问 16 站，检查建筑底面、重叠、道路和入口；琴音林模型完整可见。分别选择听音接句与自由演奏，弹完 21 个音、取消、重新进入；原碎片打卡仍可获得进度。
5. 到东南湖边进入普通全景，拖动、走动、抛竿、退出再进入。无 XR 设备应显示降级提示；头显需另测允许/拒绝、控制器、设备拔出、退出/再次进入，以及授权等待期间退出湖边。
6. 暂停菜单依次固定 5、8、12、18、22 点，返回观察天空、太阳/月亮、雾与路灯；设 300 秒完整看一轮，暂停不耗经营时间；现实同步和偏移符合本机时钟，原剧情天数不因视觉昼夜变化。低中高档各看一次。
7. 新档从起程驿楼开始：备料→制作→接单→等服务→交付，重复两次后升级。跨 3 处经营建筑完成 10 单、2 次升级，触发前三段故事；完成主线后领取第四段。新旧档分别刷新/关闭再打开，核对钱、口碑、订单、等级、碎片和章节。
8. 手机连续 15 分钟走完整路线并经营，记录设备型号、系统、浏览器、画质、最低/平均 FPS 与温升；不把桌面 FPS 当手机成绩。
9. 在三个桌面系统安装并离线启动对应包，检查载具、输入、双语、保存和湖边降级。CI 构建成功后再把这一行改为“已测”。

### 第一次发版尝试：CI 红了，根因已定位并修复

`v1.0.2` tag 与 main 都已推上远端，流水线也确实触发了——但**两条都红在 `npm run verify`**（桌面端 Release 与部署到 GitHub Pages），typecheck 与 build 都是绿的。Release 的 prepare job 因此中断，**没有生成任何安装包，GitHub 上也没有 v1.0.2 Release**（连草稿都没有）。

根因不在代码，在**基线被本地工作区污染**：

- 工作区 `public/audio/` 下躺着 17 个 Godot 的 `.import` 导入桩。`.gitignore` 里写着 `*.import`（**没进版本库**），但 `vite build` 把 `public/` 原样拷进 `dist/`，于是它们跟着上了产物。
- 唯一那一份公开数字 [release-facts.md](release-facts.md) 是**在本地**量出来的，于是基线比"干净检出"多 6,698 字节。
- CI 是全新检出，没有那些文件，[DOC] 门对账对不上就判红。症状是安静的那一种：本地全绿，线上全红。

已修：把那些桩挪出 `public/`（留在本地 `.cache/` 里，可回退）；新增产物洁净度判据（`public/` 与 `dist/` 里都不许有本地垃圾，且 `dist/` 必须等于 build 产物加上 `public/` 的逐文件拷贝）；事实对账分成两档——语义值逐字校对，体积类测量值允许一点构建环境噪声。

顺带修掉一个会在桌面上白屏的坑：收紧 CSP 之后，桌面端会拦掉 `index.html` 里那段内联的首屏 i18n 脚本（上一版 CSP 是 null，所以一直没暴露）。现在给那段脚本加上 Tauri 的 nonce 占位符，CSP 也补上了 Tauri 自己的端点。
